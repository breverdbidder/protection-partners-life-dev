# Protection Insurance Partners dev preview

Static development preview forked from [melisamikko/life-insurance-agency-template](https://github.com/melisamikko/life-insurance-agency-template) (MIT).

- Home, auto and business coverage review layout with a four-step walkthrough.
- Walkthrough is a visual demo only: no data is stored or sent.
- Goal: $1,000,000 in combined premium savings. This is a goal, not a result or a guarantee.
- The coffee or food e-card is a concept only. No provider, amount, eligibility or funding is set.
- Canopy link: https://app.usecanopy.com/c/protection-partners

Build: `npm ci --ignore-scripts && npm run build` (static export to `out/`). GitHub Actions deploys to GitHub Pages.
